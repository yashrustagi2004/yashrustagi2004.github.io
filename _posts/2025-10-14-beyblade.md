## 1. Getting started

The challenge provided a windows registry file from which the flag has to be extracted. So first I extracted the contents from it and saved it in a text file

```python
#!/usr/bin/env python3

from regipy.registry import RegistryHive

reg = RegistryHive("beyblade")

for key in reg.recurse_subkeys():
    for value in key.values:
        data = value.value
        if isinstance(data, bytes):
            try:
                data = data.decode("utf-16le")
            except:
                continue
        if isinstance(data, str) and len(data) > 3:
            print(key.path, value.name, repr(data))
```

usage: `python3 file_name.py > output.txt`


Regex used: `(piece|fragment|chunk|part|hash|value|flag).{0,5}[3-8].{0,5}(of.)?8.{0,5}`

meaning: either word is followed by 0-5 random characters, which is then followed by a sigle digit ranging from 3 to 8, which is then followed by 0-5 random characters, maybe followed by of or not and then 8, finally it is followed by 0 to 5 random characters
